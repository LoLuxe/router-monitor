# Router Monitor

Мониторинг питания роутера с уведомлениями в Telegram.

---

## Структура

```
api/
  ping.js       ← роутер стучится сюда каждые 2 мин (GET)
  status.js     ← дашборд читает статус (GET)
  check.js      ← cron-job.org вызывает каждые 3 мин (GET)
  register.js   ← подписка на уведомления (POST)
public/
  index.html    ← дашборд
```

---

## Шаг 1 — Создать Telegram бота

1. Напишите [@BotFather](https://t.me/BotFather) в Telegram
2. `/newbot` → придумайте имя → получите токен вида `7123456789:AAF...`
3. Сохраните токен — он понадобится ниже

---

## Шаг 2 — Задеплоить на Vercel

### 2.1 Загрузить проект

```bash
# Установите Vercel CLI если нет
npm i -g vercel

# В папке проекта
vercel
```

Или залейте папку на GitHub и подключите через [vercel.com](https://vercel.com).

### 2.2 Подключить Vercel KV

1. Vercel Dashboard → ваш проект → **Storage** → **Create Database** → **KV**
2. Выберите бесплатный план Hobby
3. После создания нажмите **Connect to Project** — переменные окружения добавятся автоматически

### 2.3 Добавить переменные окружения

Vercel Dashboard → проект → **Settings** → **Environment Variables**:

| Имя | Значение |
|-----|----------|
| `TELEGRAM_BOT_TOKEN` | токен от BotFather |
| `CRON_SECRET` | любая случайная строка, например `my-secret-key-123` |

После добавления — **Redeploy** проекта.

---

## Шаг 3 — Настроить cron-job.org

1. Зарегистрируйтесь на [cron-job.org](https://cron-job.org) (бесплатно)
2. **Create cronjob**:
   - URL: `https://ВАШ-ПРОЕКТ.vercel.app/api/check`
   - Schedule: каждые **3 минуты**
   - Headers: добавьте заголовок `x-cron-secret` со значением из `CRON_SECRET`
3. Сохраните

---

## Шаг 4 — Настроить роутер Keenetic

Заходим в веб-интерфейс Keenetic (обычно 192.168.1.1):

1. **Управление** → **Скрипты** или через **CLI** (SSH/Telnet)

Добавьте задачу через интерфейс Keenetic **NDMS Scheduler** или через `crontab`:

### Через SSH (если включён)

```bash
# Подключиться к роутеру по SSH
ssh admin@192.168.1.1

# Добавить в crontab (каждые 2 минуты)
crontab -e
```

Добавить строку:
```
*/2 * * * * wget -q -O /dev/null "https://ВАШ-ПРОЕКТ.vercel.app/api/ping" &
```

### Через веб-интерфейс Keenetic (проще)

Keenetic Ultra поддерживает **Планировщик задач** в разделе **Управление**:

1. Создайте новую задачу
2. Тип: **HTTP-запрос**  
3. URL: `https://ВАШ-ПРОЕКТ.vercel.app/api/ping`
4. Интервал: **2 минуты**

> Если планировщика нет в UI — используйте SSH-вариант выше.

---

## Шаг 5 — Подписаться на уведомления

1. Откройте дашборд: `https://ВАШ-ПРОЕКТ.vercel.app`
2. Напишите [@userinfobot](https://t.me/userinfobot) в Telegram, чтобы узнать свой числовой ID
3. Введите ID в поле «Уведомления в Telegram» → **Подписаться**
4. Бот пришлёт подтверждение

Повторите для каждого, кто хочет получать уведомления.

---

## Как это работает

```
Роутер → GET /api/ping каждые 2 мин
  └─ сохраняет timestamp в Vercel KV
  └─ если предыдущий ping был >5 мин назад → шлёт алерт "свет вернулся"

cron-job.org → GET /api/check каждые 3 мин
  └─ если последний ping >5 мин назад → шлёт алерт "нет света"
  └─ повтор алерта не чаще раза в 30 мин

Браузер → GET /api/status
  └─ возвращает статус, время тишины, историю последних 5 сигналов
```

## Лимиты бесплатного плана

| Ресурс | Лимит Hobby |
|--------|-------------|
| Vercel Functions | 100 GB-hours / мес |
| Vercel KV | 30 000 команд / мес, 256 MB |
| cron-job.org | Без лимита (бесплатно) |

При 2-минутном интервале роутера + 3-минутном крон: ~720 + 480 = ~1200 запросов/сутки — хорошо вписывается в лимиты.
